# Bases d'indexation - Guide utilisateur

## Présentation

Les bases d'indexation permettent aux revues de valoriser leur référencement dans les bases de données et annuaires scientifiques (DOAJ, AOJ, DDH, etc.).

La plateforme propose un catalogue partagé de bases d'indexation. Chaque revue peut indiquer dans quelles bases elle est référencée, et proposer de nouvelles bases si elles ne figurent pas au catalogue.

---

## Fonctionnalités selon votre rôle

### Administrateur de revue / Rédacteur en chef

Vous pouvez :
- **Consulter** la liste des bases d'indexation validées
- **Cocher/Décocher** les bases où votre revue est référencée
- **Proposer** une nouvelle base d'indexation (soumise à validation)

### Secrétaire de rédaction

Vous pouvez :
- **Consulter** la liste des bases d'indexation validées
- **Cocher/Décocher** les bases où votre revue est référencée

### Epiadmin (Administrateur plateforme)

Vous pouvez :
- **Créer** directement une nouvelle base d'indexation
- **Valider** ou **Rejeter** les propositions des revues
- **Modifier** les informations d'une base existante
- **Supprimer** une base d'indexation

---

## Guide pas à pas

### Indiquer les bases où votre revue est référencée

1. Accédez au **tableau de bord** de votre revue
2. Cliquez sur **Référencement & Indexation**
3. Dans la section **Bases d'indexation disponibles**, utilisez les interrupteurs pour cocher les bases où votre revue est référencée
4. Les modifications sont enregistrées automatiquement

### Proposer une nouvelle base d'indexation

Si une base d'indexation ne figure pas dans le catalogue :

1. Accédez à la page **Référencement & Indexation** de votre revue
2. Cliquez sur **Proposer une nouvelle base**
3. Remplissez le formulaire :
   - **Nom de la base** (obligatoire)
   - **URL du site** (optionnel)
   - **Logo** (optionnel - formats acceptés : SVG, PNG, JPG, WEBP)
4. Cliquez sur **Soumettre**

Votre proposition sera examinée par l'équipe d'administration. Vous pouvez suivre son statut dans la section **Vos propositions en attente**.

### Gérer les propositions (Epiadmin uniquement)

1. Accédez à **Administration > Bases d'indexation**
2. Consultez l'onglet **En attente** pour voir les propositions
3. Pour chaque proposition, vous pouvez :
   - **Valider** : la base devient disponible pour toutes les revues
   - **Modifier** : corriger les informations avant validation
   - **Rejeter** : refuser la proposition

---

## Statuts des bases d'indexation

| Statut | Signification |
|--------|---------------|
| **En attente** | Proposition soumise, en attente de validation |
| **Validée** | Base disponible pour toutes les revues |
| **Refusée** | Proposition non retenue |

---

## Questions fréquentes

**Puis-je modifier une base d'indexation existante ?**
Non, seuls les administrateurs de la plateforme (epiadmin) peuvent modifier le catalogue des bases.

**Ma proposition a été refusée, que faire ?**
Contactez l'équipe d'administration pour comprendre les raisons du refus et éventuellement soumettre une nouvelle proposition corrigée.

**Les bases cochées sont-elles visibles publiquement ?**
Non, cette fonctionnalité est réservée à la gestion interne. L'affichage public n'est pas inclus dans cette version.
